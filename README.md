# Deutsch 5 · Jahresplanung

Zentrale Jahresplanung für Deutsch im Jahrgang 5.

Dieses Repository bündelt die **übergreifende Planung**, gemeinsame Standards und die interaktive Jahresübersicht. Bereits bestehende Unterrichtsreihen bleiben zunächst in ihren eigenen Repositories und werden von hier aus verknüpft.

1. **Wunschbriefe** · Aufgabentyp 3 · bestehendes Repo: [d5ur1-wunschbriefe](https://github.com/technikerleben/d5ur1-wunschbriefe)
2. **Zootiere** · Aufgabentyp 2 · bestehendes Repo: [d5ur2-zootiere](https://github.com/technikerleben/d5ur2-zootiere)
3. **Märchen** · Aufgabentyp 6 · fünf Etappen

5. **Spannend erzählen · Zauberschule** · Aufgabentyp 1 · fünf Etappen
6. **Ganzschrift** · Aufgabentyp 4a · fünf Etappen

Aufgabentyp 5 wird nicht künstlich in Jahrgang 5 erzwungen und kann in Jahrgang 6 gezielt aufgegriffen werden.

## Gemeinsame SRL-Architektur

Die Reihen werden grundsätzlich rückwärts von der zentralen Zielaufgabe geplant:

**Zielkompetenz → Etappen → Input + identisches Merkblatt → Pflichtübungen → freiwillige Vertiefungen → Gelingensnachweis → Probearbeit → Projekte / Wiederholung → Lernerfolgskontrolle**

Die Anzahl der Etappen richtet sich nach Umfang und Lerngegenstand. Zootiere ist bewusst kompakt auf drei Etappen angelegt; ab Märchen werden fünf Etappen als Planungsrahmen genutzt.

## Struktur

- `index.html` – interaktive Jahresübersicht
- `planung/` – gemeinsame Jahresstandards und Aufgabentypen
- `01-wunschbriefe/` bis `06-ganzschrift/` – Themenordner mit Planung, Status und Verweisen
- `skill.md` – Arbeitsregeln für die Weiterentwicklung des Repositories
