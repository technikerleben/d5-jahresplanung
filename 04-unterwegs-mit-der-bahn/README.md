# 04 · Unterwegs mit der Bahn

**Status:** Planung  
**Aufgabentyp:** 4b  
**Rahmen:** fünf Etappen

## Zielaufgabe

Eine konkrete Fahrt mit mehreren Materialien planen: Verbindungen ermitteln, Umstiege erkennen, Informationen vergleichen und Entscheidungen anhand der Materialien begründen.

## Fünf Etappen

1. Fahrpläne lesen
2. Linienpläne verstehen
3. Informationen verbinden
4. Verbindungen vergleichen
5. Eine Fahrt vollständig planen
