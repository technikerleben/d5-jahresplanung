# 06 · Ganzschrift

**Status:** Planung  
**Aufgabentyp:** 4a · analysierendes Schreiben  
**Rahmen:** fünf Etappen

## Prüfungsrichtung

An einem überschaubaren Ausschnitt eine Figur charakterisieren, eine Figurenbeziehung erklären oder eine Textstelle in den Handlungszusammenhang einordnen.

## Fünf Etappen

1. In die Ganzschrift einsteigen
2. Handlung verstehen
3. Figuren untersuchen
4. Textstellen genauer untersuchen
5. Leseerfahrungen darstellen

Ein Portfolio oder Lesetagebuch kann – abhängig von den schulischen Festlegungen – als alternatives Leistungsprodukt geprüft werden. Die Typ-4a-Kompetenzen werden unabhängig davon gezielt aufgebaut.
